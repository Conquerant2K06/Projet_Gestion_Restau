# Copa del Mare — Frontend

Prototype frontend de la solution de gestion et du site e-commerce du restaurant **Copa del Mare by Elio** (Grand-Bassam, Côte d'Ivoire).

## 🚀 Démarrage rapide

Aucune dépendance, aucun build. Il suffit d'ouvrir `index.html` dans un navigateur :

- **Local** : double-cliquez sur `index.html`
- **Serveur local (recommandé)** :
  ```bash
  npx serve frontend
  # ou
  python3 -m http.server 8000
